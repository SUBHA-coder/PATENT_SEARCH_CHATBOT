Patent Search Chatbot - Project Report

1. Project Overview
-------------------
The Patent Search Chatbot is a web-based application designed to streamline the process of searching for and analyzing patents. It combines the power of Google Patents search (via SerpAPI) with advanced Large Language Models (via Groq API) to provide users with instant access to patent data and intelligent summaries.

2. Technical Architecture
-------------------------
- Backend: Python Flask server (`app.py`)
- Frontend: Single-page application (`index.html`) served by Flask
- External APIs:
  - SerpAPI: Used to query Google Patents for real-time patent data.
  - Groq API: Used to generate professional summaries of the patents using models like Llama 3 and Mixtral.
- Data Management: Session-based storage for chat history, with CSV export capabilities.

3. Detailed Workflows
---------------------

A. Installation & Setup Workflow
   1. Environment Preparation:
      - Install Python dependencies: `pip install -r requirements.txt`
   2. API Configuration:
      - Obtain API keys from Groq (for AI) and SerpAPI (for search).
      - Set environment variables: `GROQ_API_KEY` and `SERPAPI_API_KEY`.
   3. Execution:
      - Run the server: `python app.py`
      - Access the application at `http://127.0.0.1:5000`.

B. Search & Analysis Workflow
   1. User Input: The user enters a search query (e.g., "battery technology") in the web interface.
   2. Data Retrieval (Backend):
      - The `search_patents` function sends a request to SerpAPI.
      - It parses the JSON response to extract key details: Patent Number, Title, Abstract, Date, Assignee, and Link.
   3. Intelligent Summarization:
      - The `summarize_with_llm` function formats the retrieved patent data into a prompt.
      - It sends this prompt to the Groq API.
      - The system employs a fallback strategy, trying multiple models (Llama 3.1, Mixtral) to ensure reliability.
   4. Response: The frontend displays the list of patents alongside the AI-generated summary.

C. Data Management Workflow
   1. History Tracking: Every search and its result is stored in the user's session.
   2. Export: Users can download their entire search session as a CSV file via the `/export-csv` endpoint, useful for reporting and offline analysis.
   3. Session Control: Users can clear their history to start a fresh session.

4. Value Proposition & "Good Impression"
----------------------------------------
This project creates a strong positive impression for patent research for the following reasons:

- Efficiency: It drastically reduces the time needed to understand the landscape of a technology. Instead of reading dozens of abstracts manually, the AI provides a synthesized overview.
- Accessibility: It translates complex patent legalese into clear, professional summaries suitable for researchers and business professionals.
- Reliability: The backend includes robust error handling and model fallback mechanisms, ensuring the application remains functional even if one AI model is unavailable.
- User-Centric Features: The ability to export data to CSV demonstrates attention to the user's need for documentation and further analysis outside the tool.
- Modern Tech Stack: Utilizing Groq for high-speed inference and SerpAPI for accurate data ensures the application feels fast and responsive.
